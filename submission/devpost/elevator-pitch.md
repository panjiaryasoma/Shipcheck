# Elevator Pitch

## Primary

**Shipcheck is an evidence-first preflight agent that reads submission rules, inspects a software project, and tells builders what is proven, what is missing, and what still needs human review before they ship.**

## Short version

Shipcheck turns rule-bound software submission review into an inspectable workflow. A Google ADK agent interprets public competition rules with Gemini, while bounded deterministic services inspect repository, deployment, reproduction, claim, and Google Cloud evidence. The result is not a generic chatbot answer, but a traceable disposition: `READY`, `NEEDS_REVIEW`, or `HOLD`.

## One-line tagline

**Not cleared until proven.**
